# Как создать приложение VK ID и получить user token

Актуально на июль 2026. Источники:
- [dev.vk.com — Быстрый старт](https://dev.vk.com/ru/api/getting-started)
- [VK ID — Создание приложения](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application)
- [VK ID FAQ](https://id.vk.ru/about/faq/business/vkid/app/30003)

---

## Почему нет кнопки «Создать приложение»

С 2025–2026 года VK изменил процесс:

1. **Standalone-приложения** больше не создаются на старом `dev.vk.com` напрямую
2. Кабинет приложений — это **сервис авторизации VK ID**
3. Вход в него возможен **только через VK Бизнес ID** (нужен профиль бизнеса)
4. Кнопка **«Добавить приложение»** / **«Создать приложение»** появляется в разделе **«Мои приложения»** — не на лендинге и не на главной странице

Если вы открыли `id.vk.com/about/business` или `id.vk.com/business/go` и видите только описание сервиса — вы **не в кабинете**, а на промо-странице.

---

## Пошаговый алгоритм

### Шаг 0. Куда заходить (рабочие ссылки)

Попробуйте по порядку:

| № | Ссылка | Что это |
|---|--------|---------|
| 1 | **https://id.vk.ru/business/go** | Кабинет VK ID (актуальный домен) |
| 2 | **https://dev.vk.com/ru/api/getting-started** → ссылка «кабинет сервиса авторизации VK ID» | Официальный путь из документации |
| 3 | **https://dev.vk.com** → карточка «Мини-приложения» → «Создать» → вкладка «Подключение VK ID» → **«Перейти в сервис»** | Обходной путь (описан в [инструкции Tilda](https://help-ru.tilda.cc/vk-app-id)) |

> Старые ссылки `id.vk.com/...` часто делают редирект. Используйте **id.vk.ru**.

---

### Шаг 1. Войти через VK Бизнес ID

1. Откройте **https://id.vk.ru/business/go**
2. Нажмите **«Войти»** / авторизуйтесь аккаунтом ВК (админ группы)
3. Система перенаправит в **VK Бизнес ID**

Если профиля бизнеса ещё нет — VK предложит его **создать**. Это обязательный шаг, без него кнопки создания приложения не будет.

---

### Шаг 2. Создать профиль бизнеса

1. Разрешите доступ к данным
2. Нажмите **«Далее»**
3. Выберите тип:
   - **Самозанятый** — самый простой вариант для физлица
   - **ИП** или **Юрлицо** — если есть
4. Заполните данные и сохраните

---

### Шаг 3. Подтвердить профиль бизнеса (верификация)

Без подтверждения приложение можно создать, но:
- не будут доступны все настройки и ключи
- через 60 дней приложение заблокируют

Как подтвердить:
1. В кабинете VK ID появится уведомление **«Подтвердите профиль»**
2. Нажмите **«Подтвердить»** → откроется **VK Бизнес ID**
3. Подтвердите через **Т-Банк**, **Альфа-Банк** или загрузку документов вручную

Документация: [Верификация профиля бизнеса](https://id.vk.com/about/business/go/docs/ru/vkid/latest/vk-id/connection/verification)

---

### Шаг 4. Открыть «Мои приложения»

После входа в кабинет VK ID (через Бизнес ID):

1. В меню слева или сверху найдите **«Мои приложения»**
2. На этой странице должна быть кнопка:
   - **«Добавить приложение»** (FAQ), или
   - **«Создать приложение»** (полная документация)

Если кнопки нет — профиль бизнеса не создан или не подтверждён. Вернитесь к шагам 2–3.

---

### Шаг 5. Создать приложение

1. Нажмите **«Добавить приложение»** / **«Создать приложение»**
2. **Платформа:** Web
3. **Название:** например `VK Join Approver`
4. Заполните поля:

| Поле | Значение для теста |
|------|-------------------|
| Базовый домен | `localhost` |
| Доверенный redirect URL | `http://localhost` |

> Для локального теста это разрешено официальной документацией VK ID.

5. Нажмите **«Создать приложение»**
6. Подтвердите через СМС / Max / приложение ВК
7. Сохраните **ID приложения** и **Защищённый ключ**

---

### Шаг 6. Запросить право `groups` у поддержки VK

Право `groups` — **расширенное**. В настройках приложения его нет в списке базовых.

Напишите на **devsupport@corp.vk.com**:

```text
Тема: Запрос scope groups

Здравствуйте!

Прошу выдать право groups для приложения VK ID.
ID приложения: <ВАШ_APP_ID>
Задача: groups.getRequests, groups.approveRequest
ID сообщества: <VK_GROUP_ID>
Администратор: <ссылка на профиль vk.com/id...>
```

---

### Шаг 7. Получить user token

После одобрения `groups` — откройте в браузере (под админом группы):

```text
https://oauth.vk.com/authorize?client_id=ВАШ_APP_ID&display=page&redirect_uri=http://localhost&scope=groups,offline&response_type=token&v=5.199
```

Скопируйте `access_token` из адресной строки после редиректа.

> Для новых приложений VK ID прямая ссылка oauth.vk.com может не работать. Тогда используйте Authorization Code Flow через VK ID SDK или форму «Попробовать метод» на dev.vk.com.

---

### Шаг 8. Подключить к Cursor

| Secret | Значение |
|--------|----------|
| `VK_ACCESS_TOKEN` | user token (НЕ ключ сообщества) |
| `VK_GROUP_ID` | без изменений |

Запуск: `bash scripts/run_pipeline.sh`

---

## Альтернативный путь через dev.vk.com

Если `id.vk.ru/business/go` не открывает кабинет:

1. Откройте **https://dev.vk.com**
2. Найдите карточку **«Мини-приложения»** (или «Игры»)
3. Нажмите **«Создать»** / **«Подробнее»**
4. Перейдите на вкладку **«Подключение VK ID»**
5. Нажмите **«Перейти в сервис»**
6. Пройдите VK Бизнес ID (шаги 2–3 выше)
7. В разделе **«Мои приложения»** → **«Добавить приложение»**

---

## Что видите на экране → что делать

| Что видите | Что это значит | Действие |
|------------|----------------|----------|
| Лендинг «VK ID для бизнеса» | Не кабинет | Нажмите «Войти» → пройдите Бизнес ID |
| Форма создания профиля бизнеса | Нет профиля | Заполните (можно «Самозанятый») |
| «Подтвердите профиль» | Нет верификации | Подтвердите через банк или документы |
| Список приложений без кнопки | Профиль не подтверждён | Завершите верификацию |
| «Мои приложения» + «Добавить приложение» | Всё ок | Создавайте приложение (шаг 5) |

---

## Важно про ключ сообщества

Ключ из **Управление группы → Работа с API → Ключи доступа** **не работает** для заявок (error 27). Нужен именно user token с `groups`.
