# Как создать приложение VK ID и получить user token

Пошаговая инструкция для автоприёма заявок в закрытую группу.

---

## Часть 1. Создание приложения VK ID

### Шаг 1. Откройте кабинет разработчика

1. Перейдите по ссылке: **https://id.vk.com/business/go**
2. Войдите под **тем же аккаунтом ВК**, который является **администратором** вашей группы

> Если ссылка не открывается, попробуйте: https://id.vk.com/about/business/go

### Шаг 2. Создайте приложение

1. На главной странице нажмите **«Добавить приложение»** (или **«Создать приложение»**)
2. Заполните форму:

| Поле | Что указать |
|------|-------------|
| **Название** | Любое, например `VK Join Approver` |
| **Платформа** | **Web** (Веб-сайт) |
| **Иконка** | Любая (можно загрузить позже) |

3. Нажмите **«Далее»**

### Шаг 3. Укажите домен и redirect URL

Для нашей задачи (получить токен вручную, без сайта) укажите:

| Поле | Значение |
|------|----------|
| **Базовый домен** | `oauth.vk.com` |
| **Доверенный redirect URL** | `https://oauth.vk.com/blank.html` |

> Если форма не принимает `oauth.vk.com`, укажите `localhost` и redirect `https://localhost` — тогда токен получите через тестовую форму на dev.vk.com (см. часть 3).

4. Нажмите **«Готово»** / **«Создать»**
5. Подтвердите создание (СМС или приложение ВК, если попросит)

### Шаг 4. Сохраните данные приложения

После создания откроется страница настроек. Запишите:

| Параметр | Где найти | Пример |
|----------|-----------|--------|
| **ID приложения** (client_id) | Настройки приложения | `12345678` |
| **Защищённый ключ** (client_secret) | Настройки приложения | длинная строка |

Эти значения понадобятся для получения токена и письма в поддержку.

## Часть 2. Запрос права `groups` у VK

Без этого права API вернёт error 15 (Access denied).

### Шаг 5. Напишите в поддержку VK

Email: **devsupport@corp.vk.com**

Тема: `Запрос scope groups для приложения`

Текст (замените значения в угловых скобках):

```text
Здравствуйте!

Прошу выдать право groups (scope) для приложения VK ID.

ID приложения: <ВАШ_APP_ID>
Название: VK Join Approver
Задача: автоматическое одобрение заявок на вступление в закрытое сообщество
ID сообщества: <VK_GROUP_ID>
Методы API: groups.getRequests, groups.approveRequest

Аккаунт администратора сообщества: <ссылка на ваш профиль vk.com/id...>

Спасибо!
```

Дождитесь ответа (обычно несколько рабочих дней).

## Часть 3. Получение user token

### Способ A — через браузер (проще всего)

После одобрения права `groups`:

1. Подставьте свой **ID приложения** в ссылку:

```text
https://oauth.vk.com/authorize?client_id=ВАШ_APP_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=groups,offline&response_type=token&v=5.199
```

2. Откройте ссылку в браузере
3. Войдите под **админом группы**
4. Разрешите доступ приложению
5. Вас перекинет на страницу `oauth.vk.com/blank.html`
6. В **адресной строке** найдите `access_token=...` — скопируйте значение до `&`

Пример адреса после редиректа:

```text
https://oauth.vk.com/blank.html#access_token=vk1.a.XXXX...&expires_in=0&user_id=12345
```

Скопируйте: `vk1.a.XXXX...` (всё между `access_token=` и `&`)

### Способ B — через форму на dev.vk.com

1. Откройте https://dev.vk.com/ru/method/groups.getRequests
2. Прокрутите вниз до блока **«Попробовать метод»**
3. Вставьте user token и `group_id`
4. Нажмите **Выполнить**
5. Если ответ без ошибки — токен рабочий

## Часть 4. Подключение к Cursor

### Шаг 6. Обновите секреты

**Cursor Dashboard → Cloud Agents → Secrets** (репозиторий `vk-poisk-musicantov`):

| Secret | Значение |
|--------|----------|
| `VK_GROUP_ID` | ID группы (без минуса) — без изменений |
| `VK_ACCESS_TOKEN` | **user token** из шага 3 (НЕ ключ сообщества!) |

### Шаг 7. Запустите тест

В Cloud Agent отправьте:

```text
bash scripts/run_pipeline.sh
```

Ожидаемый результат:

```text
OK VK API groups.getRequests reachable
OK dry-run: would approve N users
```

### Шаг 8. Включите реальный приём

После успешного dry-run добавьте секреты:

| Secret | Значение |
|--------|----------|
| `APPROVE_ALLOW` | `yes` |
| `DRY_RUN` | `no` |

## Частые проблемы

| Ошибка | Причина | Решение |
|--------|---------|---------|
| **27** | Ключ сообщества вместо user token | Замените `VK_ACCESS_TOKEN` на user token |
| **15** | Нет права `groups` | Дождитесь ответа devsupport или проверьте scope |
| Не вижу «Добавить приложение» | Не вошли в кабинет | Войдите на id.vk.com/business/go |
| `redirect_uri` mismatch | Неверный redirect в настройках | Укажите `https://oauth.vk.com/blank.html` в приложении и в ссылке |
| Токен истёк (~1 час) | Нет `offline` в scope | Запросите `offline` в поддержке или получайте токен заново |

---

## Краткая схема

```text
id.vk.com/business/go → Создать приложение (Web)
    ↓
devsupport@corp.vk.com → запросить scope groups
    ↓
oauth.vk.com/authorize?...scope=groups,offline... → скопировать access_token
    ↓
Cursor Secrets → VK_ACCESS_TOKEN = user token
    ↓
bash scripts/run_pipeline.sh
```
