# Как получить user token для автоприёма заявок

## Почему ключ сообщества не работает

Ключ из **Работа с API → Ключи доступа** — это **ключ сообщества**.

Методы `groups.getRequests` и `groups.approveRequest` **не принимают** ключ сообщества. VK отвечает:

```text
error_code: 27 — Group authorization failed: method is unavailable with group auth.
```

Нужен **ключ доступа пользователя** (администратора группы) с правом **`groups`**.

---

## Шаг 1. Создайте приложение VK ID

1. Откройте [id.vk.com](https://id.vk.com) → **Мои приложения** → **Создать**
2. Тип: **Standalone-приложение** или **Веб-сайт**
3. Запомните **ID приложения** и **Защищённый ключ**

---

## Шаг 2. Запросите право `groups` у поддержки VK

Напишите на **devsupport@corp.vk.com**:

```text
Тема: Запрос scope groups для приложения

Здравствуйте!

Прошу выдать право groups (scope) для приложения VK ID:
- ID приложения: <ВАШ_APP_ID>
- Название: <название>
- Задача: автоматическое одобрение заявок на вступление в закрытое сообщество
- ID сообщества: <VK_GROUP_ID>
- Методы API: groups.getRequests, groups.approveRequest

Администратор сообщества: <ссылка на ваш профиль VK>
```

Без этого права токен не сможет вызывать нужные методы (ошибка 15).

---

## Шаг 3. Получите user token (после одобрения)

Откройте в браузере (под аккаунтом **администратора группы**):

```text
https://oauth.vk.com/authorize?client_id=ВАШ_APP_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=groups,offline&response_type=token&v=5.199
```

После подтверждения в адресной строке будет `access_token=...` — скопируйте его.

> `offline` даёт бессрочный токен (если VK разрешит). Без `offline` токен живёт ~1 час.

---

## Шаг 4. Обновите Cursor Secrets

| Secret | Значение |
|--------|----------|
| `VK_ACCESS_TOKEN` | **user token** из шага 3 (НЕ ключ сообщества) |
| `VK_GROUP_ID` | без изменений |

Запустите снова:

```text
bash scripts/run_pipeline.sh
```

---

## Быстрая проверка токена

На странице [groups.getRequests](https://dev.vk.com/ru/method/groups.getRequests) внизу есть форма «Попробовать метод».
Вставьте user token и `group_id` — если работает, токен подходит.

---

## Если поддержка откажет

Автоприём через API с ключом сообщества **невозможен** по ограничениям VK.
Варианты:

1. Принимать заявки вручную в приложении ВК
2. Сделать группу открытой (без модерации заявок)
3. Использовать сторонний сервис автоматизации ВК (если у них есть user token)
